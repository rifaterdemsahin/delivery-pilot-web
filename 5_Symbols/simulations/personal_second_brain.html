Personal Second Brain 🧠

Build your neural network with Obsidian and AI.

✅ Setup Checklist

Get the app from obsidian.md and install it.
Create a "My Second Brain" vault in your Documents folder.
Enable Community Plugins and install Text Generator for AI writing.
Install Smart Connections for semantic search and chat.
Add your OpenAI (or other) API key to the plugin settings.
Set up PARA: 00_Inbox, 10_Projects, 20_Areas, 30_Resources, 40_Archives.
Write a thought in 00_Inbox and check Smart Connections sidebar.
Open Graph View to see your note network.
Ask a question in Smart Connections pane about your note.
Verify your local AI second brain is operational.
